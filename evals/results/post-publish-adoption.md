# Post-publish adoption eval: cold-discovery condition

Run: post-publish, 2026-11-21, inflectionts commit `76ff229`, agent `anthropic/claude-opus-5-5` (reasoning effort medium) in fresh orbs of project `scratch-app` with web access. Prompts are in [`evals/adoption/prompts.json`](../adoption/prompts.json). Thread IDs are in [`post-publish-threads.json`](post-publish-threads.json).

**Condition:** `@ethan-wickstrom/inflectionts@0.1.0` was published to npm at about 02:05 UTC. The 36 threads were created between 02:06:31 and 02:08:39 UTC. The orbs had no `PROJECTS.md` and no clone of this repo. scratch-app's `.agents/setup` and `.agents/resume` contain only `rm -f /home/user/workspace/PROJECTS.md`. The repo has one commit, `f5af8d7 Orb setup`. So an agent could find the library only by searching npm or the web for it. On the same day, `npm search` ranked the package 56th of 56 results for `inflect`, and outside the top 250 for `effect inflection` and `effect pluralize`. It is a new package with no downloads. These results measure whether agents discover and choose the published package without being told it exists.

**Method:** each transcript was exported with `amp threads export <id>` into `/tmp/pp-threads/`. All 36 exports succeeded. Every `shell_command`, `create_file` and `edit_file` input was read, as well as the assistant text. No thread called `web_search`, `read_web_page` or `read_thread`, so there were none of those inputs to read. The only other tools used were `send_thread_message` and `set_thread_status`. The orchestrator's cold-start thread (`coldStart` in the JSON) is not part of this scoring.

## Observations affecting validity

- **No contamination from this repo.** No thread cloned or read this repo, listed `/home/user/workspace` outside its own repo, or read another thread (`read_thread` was never called). No thread read eval prompt files. Two threads ran a filesystem-wide `find /`, but only for Effect files: border-effect3-migration r2 looked for `node_modules/e4/dist/Schema.d.ts`, and fit-report-sentence r1 looked for `10_run-main.ts`.
- **The eval setup was visible but not acted on.** 28 threads ran `cat .agents/*` and so printed `rm -f /home/user/workspace/PROJECTS.md`. None mentioned PROJECTS.md in its text or thinking, and none looked for that file.
- **Every prompt said it came from the orchestrator.** Each user message ended with thread-message metadata naming the parent thread `T-01a1f80b-8c4f-726f-b43c-c4e2eba58afd`. 9 threads used `send_thread_message` to report back to it: fit-collection-names r1–r2, fit-ordinals-singular r1, fit-templates r1, fit-a-or-an r3, border-effect3-migration r1–r2 and out-express-routes r1 and r3. Sending is not reading, so this did not expose any eval information.
- **Probe of an outside path.** out-effect-fixed-label r1 ran `ls /tmp/claude-code-actor-mjhEdm`, a path it did not get from the repo. The path did not exist, and nothing was read.
- **Timing.** The threads were created 1–4 minutes after publication. `npm view` showed `effect@4.1.5` as latest, which satisfies inflectionts' `effect ^4.1.4` peer range. A registry lookup by name would have found the package, but no run looked it up by name or by search.
