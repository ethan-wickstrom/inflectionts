## Code Style

- Make Effect `Schema` the executable definition of external data and derive domain types from it. Decode untrusted inputs once at boundaries, trust the decoded type afterward, model expected rejections with `Schema.TaggedError`, and reserve runtime invariant checks for already established invariants.
- Never author `any`, assert to `unknown`, use `as` or double assertions, or erase Effect error or service channels. Rely on contextual typing, schema inference, constructors, and `satisfies`, resolve unclear types from defining source, and state explicitly when a type cannot be verified.
- Use `Predicate` helpers from `effect` (such as `Predicate.isObject` and `Predicate.isString`) instead of hand-writing runtime type guards, composing them with `Predicate.and`, `Predicate.or`, `Predicate.not`, and `Predicate.compose`.
- Model exclusive alternatives with tagged unions and match application branches exhaustively with Effect `Match`, keeping payloads inside variants. Use plain conditions and early returns for local guards.
- Use `Effect.fn("Name")` for traced reusable operations, `Effect.fnUntraced` for library internals and hot paths, and `Effect.gen` for inline values instead of wrapping `Effect.gen` in a plain function. Pass combinators as trailing arguments to `Effect.fn` instead of `.pipe`, annotate contracts with `Effect.fn.Return<A, E, R>`, pass `{ self }` to bind `this` in `Effect.gen`, and always `return yield*` on typed failures so TypeScript narrows unreachable paths.
- Keep pure calculations as ordinary functions, preserve exported `Effect<A, E, R>` channels, and never hide a Promise or unexecuted Effect inside a success value.
- Write options-object types inline with `readonly` fields and explicit `| undefined` on optional properties to satisfy `exactOptionalPropertyTypes`, extracting a named type only when shared across APIs or driven by conditional types.
- Use static imports only and never use dynamic `await import(...)` or `require` unless explicitly asked. Do not add defensive checks, defensive `try`/`catch` blocks, or fallbacks that conceal broken contracts.
- Keep source compatible with `verbatimModuleSyntax` and `erasableSyntaxOnly` using inline `type` imports and omitting runtime-emitting enums, parameter properties, and legacy namespaces.

- Distinguish enqueueing (`send`), mailbox processing (`sendAndAwait` from `@xstate/effect` or `@xstate/effect/test`), observation (`waitFor`, which fails with `ActorStoppedError` on both stop and error, plus `snapshots`, `emitted`, `deadLetters`), and completion (`join`), noting `EffectActor` omits `trigger` and `select`.
